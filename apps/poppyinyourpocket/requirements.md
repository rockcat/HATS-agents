# Poppy In Your Pocket

This is a brand new APP written in flutter to run on mobile and test on web

Poppy in Your Pocket is a mobile app which uses the embodiment API to implement a single user facing avatar which listens for command and can takle images using the phone camera.

The aim is to provide a single agent which is customised to the specific neds of the user. 
The agent will always have some basic tools:

- Memory
- Kanban for tracking tasks
- Personal imap based Email address
- Camera access for photo or video. This  will need a new MCP developed for webcam access on phone and browser
- Face recognition,. This will need a new MCP developed for face recognition - it needs to be a lightweight as possible.

The base agent profile will be selected by the user on first use.
The agent should use the camera to try and recognise the person using the app. If they are not recognised then the agent will ask the user their name and stor ethe facial data with the name in a db.
The main user of the of the agent should be identified when the agent is first cionfigured and stored. This user has more rights and control over the agent than other people.

The user will make request of the agent through voice mainly but sometimes by typing.

The agent should be represented by a .VRM model selected from a library by the user. New models may be uploaded by the user. The screen shoudl show a headshot view and all speech must be animated as well as some general animations to convey mood and conversation when avaialble in the model.

a .vrm model should be chosen by the user and a library of .vrma files stored. these may be generated by importing mixamo files and converting durin gdev elopment.
Then when speaking the charcater can use a suitable animation to reflect the emotion in the conversation
